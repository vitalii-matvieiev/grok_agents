# План реалізації демо Grok Bot

## Результат

Публічний статичний демо-стенд українською мовою, який можна відкрити в браузері під час виступу. Він не залежить від авторизації в Trello або Linear та не змінює реальні дані.

## Склад

1. Головний екран «Операційний штаб Віталія» з вісьмома агентками.
2. Інтерактивний сценарій «Зустріч → Trello/Linear → дайджест».
3. Інтерактивний сценарій «Дослідження → контент → перевірка».
4. Preview-дошка з картками Trello та задачами Linear.
5. Каталог 56 офіційних юзкейсів Grok Bot з пошуком і фільтрами.
6. Окрема пам’ятка ведучого з репліками для 5–7-хвилинного демо.

## Перевірка

- сторінка працює локально без збірки;
- сценарії перемикаються і проходять усі кроки;
- пошук і фільтри каталогу працюють;
- мобільне і десктопне компонування не ламається;
- GitHub Pages публікує каталог `site`.

## Межі безпеки

Всі зовнішні дії показуються як попередній перегляд. Надсилання повідомлень, публікація, бронювання, платежі й зміни в бойових системах залишаються за явним підтвердженням користувача.
