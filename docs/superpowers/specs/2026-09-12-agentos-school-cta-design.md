# CTA to AI Orchestrator School

## Goal

Give visitors a clear path from seeing Matvieiev AgentOS in action to learning how to build their own AI team through the AI Orchestrator School.

## Placement and content

Two links use the same Ukrainian label: **«Створити свою AI-команду»**.

1. The hero link sits beside the existing scenario link. It uses the restrained secondary button treatment so the AgentOS interaction remains the primary on-page action.
2. A dedicated conversion block follows the 56-skills catalogue. It uses a short outcome-focused message and the primary button treatment because the visitor has just seen the full breadth of the team.

## Destination and attribution

Both links point to the AI Orchestrator School:

`https://www.matvieiev.com/ai-orchestrator-school/`

The shared UTM parameters are:

- `utm_source=agentos.matvieiev.com`
- `utm_medium=referral`
- `utm_campaign=ai_orchestrator_school`

The CTA placement is distinguished with `utm_content=hero_cta` and `utm_content=catalog_cta` respectively. This intentionally replaces the supplied sidebar attribution, because traffic now originates on AgentOS rather than the main-site sidebar.

## Interaction and accessibility

Links open in the same tab and are ordinary anchors, preserving browser affordances and keyboard navigation. On compact screens, the hero actions and conversion block stack vertically with full-width buttons. No automatic navigation or additional tracking code is introduced.
