# Grok Bot: карта юзкейсів і адаптація для Віталія

- Документація про навички та рутини: https://docs.x.ai/grok-bot/skills-routines-and-automations

YouTube-пошук використовувався для пошуку публічних демонстрацій, однак повний і стабільно відтворюваний перелік ролей взято з першоджерела xAI. Це прибирає дублікати, рекламні перекази та сценарії, що стосуються інших продуктів із назвою Grok.

## Найсильніші сценарії для Віталія

1. Chief of Staff + Daily Briefing Writer — один ранковий пакет по всіх проєктах.
2. Meeting Prep Buddy + Status Report Writer — підготовка до зустрічі та контроль домовленостей після неї.
3. Call FAQ Miner + Feature Request Tracker — голос клієнта в продуктову чергу.
4. Competitive Intelligence Analyst + Social Media Manager — дослідження в контент.
5. Account Research Specialist + Sales Outbound — партнерські списки й персоналізовані чернетки.
6. Pipeline Analyst + Account Health — ризики та можливості без ручного перегляду CRM.
7. Bug Reproduction + Playtest Operator — підтверджений repro-пакет у Linear.
8. Presentation Designer + Deck Updater — матеріали до виступів і оновлення після discovery.
9. SEO/AEO Auditor + Paid Media Creative Strategist — контроль органічного та платного росту.
10. Prototype Builder + Personal Site Builder — швидка перевірка ідей із live URL.

## Правило маршрутизації

- Trello: операції, контент, партнерства, продажі, особисті задачі.
- Linear: продукт, розробка, баги, сайти й автоматизації.
- Змішаний кейс: головна картка Trello + технічний issue Linear + взаємні посилання.

## Межі

Без додаткового погодження можна готувати аналіз, чернетки, preview-картки та внутрішню структуру задач. Надсилання, публікації, запрошення, платежі, бронювання, зміни доступу й видалення залишаються за явним підтвердженням Віталія.
