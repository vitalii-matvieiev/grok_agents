# Grok Bot — операційний штаб Віталія

Україномовний операційний штаб із восьми Grok Bot агенток.

## Що показує система

- координацію спеціалізованих агенток через Соломію;
- перетворення нотаток зустрічі на preview задач у Trello та Linear;
- перетворення дослідження на контентний пакет із перевіркою фактів;
- контрольні точки, де потрібне рішення людини;
- каталог усіх 56 офіційних ролей Grok Bot.

## Запуск локально

Відкрийте `site/index.html` у браузері або запустіть будь-який статичний вебсервер із каталогу `site`.

## Безпека

Trello/Linear-картки на сторінці є локальним попереднім переглядом. Сторінка не має ключів, не виконує зовнішніх запитів і не змінює бойові дані.
